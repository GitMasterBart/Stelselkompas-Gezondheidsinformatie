# Stelselkompas v6

## GitHub Pages
Plaats de inhoud in de root van een repository, kies bij Settings > Pages voor GitHub Actions en push naar `main`.

## Lokaal
Start in deze map: `python3 -m http.server 8000`.

## Direct openen
De portfoliodata is ook ingebed in `data/portfolio-data.js`. Daardoor kan `index.html` rechtstreeks worden geopend zonder lokale webserver. Voor GitHub Pages blijft dezelfde versie bruikbaar.
